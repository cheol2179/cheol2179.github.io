MARKON STORAGE BACKUP은 내부 업무 시스템과 디자인 작업 공간의 원본 파일을 보호하기 위한 관리자 전용 백업 도구입니다. 관리자가 승인한 Google Drive에 업무 파일의 복사본을 보관하도록 설계했습니다.

INTERNAL ADMINISTRATIVE TOOL · NOT A PUBLIC LOGIN SERVICE

백업 처리 구조

01 / SOURCE

Supabase Storage

MARKON Workspace 및 Design Studio에서 사용하는 업무 파일과 디자인 자산을 백업 대상으로 사용합니다.

02 / TRANSFER

GitHub Actions · rclone

관리자 인증을 거쳐 파일을 복사하고 백업 결과를 검사하도록 설계했습니다.

03 / DESTINATION

Google Drive

관리자가 지정한 Drive 백업 폴더에 파일 복사본과 이전 버전 이력을 보관합니다.

Google Drive 접근 권한

이 도구는 Google Drive 전체 접근 권한(https://www.googleapis.com/auth/drive)을 요청합니다. 이 권한은 계정 내 다른 파일에도 기술적으로 접근할 수 있지만, 백업 스크립트는 관리자가 지정한 목적지 폴더를 사용하도록 구성되어 있습니다.

Google 계정 연결은 승인된 관리자가 직접 진행합니다. 현재 자동 백업 설정은 검증 중이며, 별도의 공개 로그인 서비스는 제공하지 않습니다.
