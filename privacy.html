개인정보처리방침

Google 사용자 데이터 접근 범위, 데이터 처리와 보관 및 삭제 원칙을 안내합니다.

최종 수정일: 2026년 10월 20일

1. 목적 및 적용 범위

MARKON STORAGE BACKUP은 MARKON 내부 관리자 전용 파일 백업 도구입니다. MARKON Workspace 및 Design Studio가 사용하는 Supabase Storage의 업무 파일을 승인된 Google Drive 백업 폴더에 복사하기 위해 사용합니다. 공개 로그인 서비스를 제공하지 않습니다.

2. Google 데이터 접근 범위

Google OAuth에서 전체 Drive 접근 권한(https://www.googleapis.com/auth/drive)을 요청합니다. 이 권한은 승인된 계정의 Drive 파일을 조회·읽기·생성·수정·삭제할 수 있는 폭넓은 권한입니다. 실제 자동 백업은 지정된 백업 폴더를 목적지로 사용하도록 설계했습니다.

  • 처리 데이터: 지정된 백업 파일의 내용, 이름, 경로, 크기, 수정 관련 메타데이터
  • 작업: 백업 파일 생성, 갱신, 이전 버전 보관, 결과 확인
  • 제외: 광고, 마케팅, 프로파일링, 개인 파일 분석, Google 사용자 데이터 판매

3. 처리 과정 및 제3자 서비스

파일 원본은 Supabase Storage에 보관되고, GitHub Actions에서 실행하는 rclone을 통해 관리자 승인 Google Drive로 사본을 전송합니다. OAuth 인증 정보 및 토큰은 공개 페이지가 아닌 비공개 GitHub Actions Secrets에서 관리합니다. Google Drive와 GitHub Actions는 백업 업무를 위한 서비스 제공자로 사용합니다.

4. 보호 조치

관리자 승인 절차와 OAuth를 적용하며 비밀번호·토큰을 공개 저장소에 게시하지 않습니다. 백업 작업은 원본의 삭제보다 복사와 검증을 우선합니다. Google API 사용자 데이터는 본래 백업 목적 외에 사용하거나 광고에 제공하지 않습니다.

5. 보관, 삭제 및 권한 철회

백업 자료는 관리자가 내부 업무 보관 목적에 따라 보유하며, 현재 일괄 자동 삭제 기간을 설정하지 않았습니다. 관리자는 Google Drive에서 백업 파일을 삭제하거나 Google 계정 보안 설정에서 이 앱의 OAuth 권한을 철회할 수 있습니다. 권한 철회만으로 기존에 복사된 파일이 삭제되지는 않습니다.

6. 문의 및 권리

Google 계정 소유자는 접근 권한을 철회할 수 있습니다. 백업 데이터 및 삭제 관련 문의는 공식 문의 채널을 이용하되, 공개 문의에는 개인 정보나 비밀키를 쓰지 마세요.

7. Google API 정책

Google API로 받은 사용자 정보는 백업 수행 용도로만 사용하며 Google API Services User Data Policy 및 Limited Use 요건에 따라 취급합니다. 처리 방식이 변경되면 본 방침도 갱신됩니다.

English Summary

This internal administrative tool uses Google Drive OAuth full-access scope to create and verify backup copies of designated MARKON business assets. Google API data is used only for backup operations, not advertising or sale. Tokens are stored in private GitHub Actions secrets; copies remain in the administrator's Google Drive until deleted. The administrator can revoke access in Google Account settings.
